# MYRA - AI Voice Assistant

MYRA is an AI voice assistant built with Vite + TypeScript.

## How to run

1. Clone the repo
2. Install dependencies:
   bun install
3. Copy `.env.example` to `.env`, then add your own API key
4. Start the app:
   bun run dev

## Build

bun run build

## Warning

Never commit your API key to GitHub.
